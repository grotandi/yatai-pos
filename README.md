# 屋台レジ — 使い方と公開手順

無料の GitHub Pages で公開し、Androidタブレットの Chrome で開いて使います。サーバ代はかかりません。
一度ネットにつないで開けば、その後は**オフラインでも動きます**。

## 1. GitHub Pages で公開する（PCで1回だけ）

1. https://github.com でアカウントを作る（あれば不要）
2. 右上の「＋」→「New repository」
   - Repository name：`yatai-pos`（なんでもOK）
   - **Public** を選ぶ → 「Create repository」
3. 作ったリポジトリの画面で「uploading an existing file」（または「Add file」→「Upload files」）
4. 次の5つをまとめてドラッグ＆ドロップ → 下の「Commit changes」
   - `index.html` `sw.js` `manifest.json` `icon-192.png` `icon-512.png`
5. リポジトリの「Settings」→ 左の「Pages」
   - Source：「Deploy from a branch」、Branch：`main` / `/(root)` →「Save」
6. 1〜2分待つと、同じ画面に `https://ユーザー名.github.io/yatai-pos/` が表示されます

※ コードは公開されますが、**売上データやDiscordのURLはタブレットの中にだけ保存**されるので公開されません。

## 2. タブレットに入れる

1. タブレットの Chrome で上のURLを開く（ネット接続が必要なのはこの時だけ）
2. Chrome右上の「︙」→「ホーム画面に追加」（または「アプリをインストール」）
3. 以後はホーム画面のアイコンから起動（全画面・横向きで開きます）
4. 「設定」（初期パスワード **1234**）を開き、まず
   - パスワードを変更
   - 5商品の値段を入力して「値段を保存」

## 3. Discord で他の端末から見る（任意）

1. Discordでサーバーを作る（自分だけのサーバーでOK）
2. 通知用チャンネルの「⚙ チャンネルの編集」→「連携サービス」→「ウェブフック」→「新しいウェブフック」→「ウェブフックURLをコピー」
3. レジの「設定」→「Discord連携」にURLを貼って「保存」→「テスト送信」
4. 会計・取消のたびにメッセージが届きます。オフライン中の分は貯めておき、ネットにつながった時（スマホのテザリング等）にまとめて送ります
5. 「CSVをDiscordに送る」で集計CSVもチャンネルに送れます

## 4. データを消さないために

- ブラウザの「閲覧データを削除」でこのサイトのデータを消さない／Chromeをアンインストールしない／シークレットタブで使わない
- 「設定」→「データ出力・保護」に「データ保護：有効」と出ていれば、容量不足などでブラウザが勝手に消すことはありません
- 念のため、休憩時や1日の終わりに **「バックアップを保存」** と **「CSVをダウンロード」**（タブレットの「ダウンロード」フォルダに入ります）
- 消えてしまったら「バックアップから復元」で元に戻せます。Discord連携していれば全会計の記録がチャンネルにも残っています

## 機能まとめ

- 商品ボタンでカートに追加、＋/−で個数調整、テンキー・「ちょうど」・¥1,000/¥5,000/¥10,000でお預かり入力 → おつりを大きく表示
- 会計ごとに番号札を自動で割り当て（日ごとに1から、設定した枚数で使い回し）。レジ画面の番号札をタップすれば手で変更可。会計後に大きく表示
- 「直前の会計を取消」、ログ画面から任意の会計を取消／取消を戻す
- ログ：日ごとの商品別集計と会計一覧（番号札・会計No.付き、番号札で検索可）
- CSV：全期間・日ごと×商品ごと（単価・数量・小計、日計、全期間合計）。Excelでそのまま開けます
- 値段変更は以後の会計にだけ反映（過去の記録は売れた時点の値段のまま）

## 更新したいとき

GitHubで同じ名前のファイルを上書きアップロードしたあと、`sw.js` 2行目の `yatai-pos-v1` を `v2` などに変えてアップロードし、タブレットでネットにつないだ状態で2回開き直すと新しい版になります。
